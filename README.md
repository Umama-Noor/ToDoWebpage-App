# ToDo Webpage App

A simple and powerful ToDo Webpage App to manage daily tasks. Add, complete and delete tasks easily with a clean interface.

## ✨ Features
- Add new tasks
- Mark tasks as completed
- Delete tasks
- Clean and simple design
- Responsive layout

## 🛠️ Built With
- HTML5
- CSS3
- JavaScript

## 🚀 How To Use
1. Download / Clone this repository
2. Open `index.html` in any browser
3. Add your tasks and manage them
